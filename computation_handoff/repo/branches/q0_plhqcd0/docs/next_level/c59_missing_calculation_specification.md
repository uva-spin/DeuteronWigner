# C59 blocker

C60/IFSUPPORT must derive a source-ordered direct-contact embedding from qg ket through the exact retained q intermediate to qg bra, including ordered left/right field projectors, before any common-support product, finite four-HO kernel, color reduction, or qg contact matrix is evaluated. The C57 canonical q-to-qg mask may be used only after this derivation proves its role.
