# C45/MODES finite-projection specification

C45/MODES must close four source-qualified interfaces before C44 can project
the C43 action: (1) finite longitudinal cell length, measure, and boundary
phase; (2) normalized 2D harmonic-oscillator mode functions, oscillator
convention, and transverse phase; (3) explicit source-normalized light-front
spinor and physical-polarization overlap formulas in that basis; and (4) the
global-color and zero-mode projection compatible with a gauge-covariant
colored matching probe and its residual boundary completion.

It must provide equations, convention maps, overlap integrals, independent
checks, and hashes.  Only then may C44 generate q/qg bases, the exact
triplet projector, Hamiltonians, vertices, constrained matrices, and maps.
