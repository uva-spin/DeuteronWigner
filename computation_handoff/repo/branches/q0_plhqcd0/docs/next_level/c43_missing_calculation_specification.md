# C44/HQCD projection specification

C44/HQCD must project C43’s locked, source-derived action into the physical
C32 finite basis: (K=9/2,11/2,13/2), antiperiodic positive half-integer
fermions, periodic positive nonzero integer gluons, and the declared
(N_{\max},b_{\rm HO}) trajectory. It must evaluate normalized mode-overlap
matrix elements for the free q/qg Hamiltonians, exact SU(3) q-to-qg vertex,
instantaneous/constrained/boundary/zero-mode terms, spacelike JMY Wilson
emission, bilocal measurement, physical counterterm conditions, and
overlap-based refinement maps.

C44 must never use or rescale C40 arrays. It must prove each numerical array
against the C43 symbolic term, source locator, and independent mode-overlap
check before a later package can resume one-loop work.
