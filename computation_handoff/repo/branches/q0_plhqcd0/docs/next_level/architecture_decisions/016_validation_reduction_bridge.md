# ADR-016: Validation-only bridge to C2 reductions

Status: accepted for C3

Pilot views reuse C2 `ReductionId`, `NativeReduction`, and
`ReductionRegistry`, but occupy a separate validation registry. The accepted
216 identities and production plan are immutable. Regulated pilot integrals
are not labeled as matched PDFs, GPDs, TMDs, or currents.
