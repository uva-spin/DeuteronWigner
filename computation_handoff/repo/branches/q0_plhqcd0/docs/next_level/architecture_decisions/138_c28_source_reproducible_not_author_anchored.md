# ADR 138: source-reproducible W is not author-anchored W

Status: accepted.

Successful execution of exact public code, data, cuts, engine, and joint source
members supports `SOURCE_REPRODUCIBLE_LOWQT_W_VALIDATION`. It does not support
an author-anchored label without an author- or repository-owned frozen number.
The narrower tier closes a reproducibility gap without weakening historical
source-process or physical-input gates.
