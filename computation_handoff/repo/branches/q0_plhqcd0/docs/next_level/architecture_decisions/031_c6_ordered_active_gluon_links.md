# ADR 031: Ordered active-gluon link identity

**Decision:** Store two complete adjoint C5 path objects in left/right order
inside the active-gluon operator. Order, orientations, endpoint fibers,
closures, and trace closure are identity fields.

**Reason:** A two-field-strength correlator contains an ordered link pair, not
a set. Swapping or reversing one leg changes the operator.

**Status:** Exact identity constraint in the C6 pilot.
