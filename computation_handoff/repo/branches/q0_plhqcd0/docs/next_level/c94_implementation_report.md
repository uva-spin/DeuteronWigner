# C94/IFEQUIVAPI2

C94 provides a direct immutable facade over unchanged, authenticated C93 capsule content. It exposes exact-order pair pagination and lookup, full normalized programs, primitive fileset families, typed-expression/theorem access, pair proof records, and a no-leaf public checker. Exhaustive capsule-versus-facade regression closes for all 154,830 pairs; no historical-descendant comparison occurs here.
