# ADR 042: Reduced H0 qqq--qqqg vertex boundary

**Decision:** Implement one reduced canonical emission block with shared
coupling and explicit color action, and construct absorption solely as its
adjoint.

**Reason:** This is sufficient to test sector coupling, conservation laws,
complete color multiplicities, and Hermiticity without pretending to provide
a renormalized physical QCD vertex.

**Status:** H-B validation boundary only; instantaneous terms,
counterterms, running, and complete interaction kernels are H1/H2 work.
