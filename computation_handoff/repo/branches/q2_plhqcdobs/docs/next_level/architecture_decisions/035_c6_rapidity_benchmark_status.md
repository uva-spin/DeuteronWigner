# ADR 035: Rapidity cancellation is benchmark-only

**Decision:** Test the derivative with respect to an analytic rapidity log
after exactly one half-soft subtraction. Retain unresolved UV finite matching
and do not assign a physical scheme.

**Reason:** Regulator-log cancellation is necessary but insufficient for a
matched QCD TMD.

**Status:** Validation-only cancellation at one Wilson order.
