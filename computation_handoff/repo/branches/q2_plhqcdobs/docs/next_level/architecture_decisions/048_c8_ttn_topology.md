# ADR 048: TTN topology and symmetry indices

**Decision:** Use the physical three-quark binary coupling tree with explicit
mode, OAM, helicity, flavor, color, permutation, \(J^z\), and resolution
indices. Forbidden blocks are absent.

**Reason:** Dense storage followed by clipping does not enforce symmetry or
expose the physically relevant entanglement cuts.

**Status:** Exact finite-\(qqq\) representation validated.
