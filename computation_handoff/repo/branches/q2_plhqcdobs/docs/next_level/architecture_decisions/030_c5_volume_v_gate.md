# ADR 030: Volume V matching/evolution entry remains closed

**Decision:** Evolution or process use requires a closed regulated operator
basis, LF-to-QCD matching, completed UV/rapidity/soft/link-shortening maps,
rank-aware scheme/evolution identity, and process link/color/Glauber status.

**Reason:** Evolving an unmatched pilot would assign it a false QCD scheme.

**Status:** Closed downstream gate.
