# C98/IFHISTPUBLIC2 implementation report

C98 exposes exactly three immutable public theorem-input methods.  Pair normal
forms read through C97's authenticated C93 zran/key transport.  Pair proof
inputs read through C97's frozen result-blind operand transport.  Primitive
records read through a compact C98 location index over unchanged C94 primitive
family payloads.  No normal form, operand, primitive record, theorem, or
checker is reconstructed.

The C98 package contains pair identity/order and primitive-location metadata
only.  It does not copy C93 normal forms, C97 operand records, or primitive
scientific content.  C98 makes no historical-versus-current-descendant
comparison and creates no downstream physics object.
