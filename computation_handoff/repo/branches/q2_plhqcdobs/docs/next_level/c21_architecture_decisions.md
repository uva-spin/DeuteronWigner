# C21 architecture decisions

- Anomalous dimensions retain expansion, logarithm, sign, representation,
  flavor-threshold, and source identity.
- Quark and gluon kernels are separate; nonperturbative Casimir scaling is not
  assumed.
- External kernel data require machine-readable covariance and complete
  scheme metadata; otherwise they remain qualitative or exploratory.
- Finite-order curl is an uncertainty, never a fit target.
- Threshold history and transverse rank are immutable member identity.
- Nuclear blocks evolve separately and reconstruct the total afterward.
- Matching capability and evolution capability are distinct matrices.
- Process-readiness is interface-only and has no production edge.
