# C28 unresolved physics and evidence gaps

C28 closes a public-source reproduction gap, not the project’s microscopic
spin-1 physics program. The reproduced calculations are external proton
Drell–Yan and proton/deuteron-target SIDIS data-model records from ART25. A
deuterium experimental target in an ART25 SIDIS dataset is not a microscopic
spin-1 deuteron prediction.

The following gates remain open:

- no author-provided or repository-frozen ART25 numerical output was found;
- no source-identical Drell–Yan fixed-order and asymptotic partner closes all
  measurement, cut, scheme, mass, scale, rank, and order identities;
- no source-identical SIDIS fixed-order/asymptotic partner was found;
- therefore the reproduced result is low-qT W only, never full W+Y;
- explicit permission to redistribute the transferred `MSHT20_REP` grids is
  absent;
- there is no calibrated, covariance-preserving map between the external
  ART25 ensemble and the project microscopic nucleon operator boundary;
- no proton result is promoted to a spin-1, nuclear, matched-total, T-odd,
  inference, or production capability.

The next package should build the bridge contract without fitting it: exact
operator/scheme/scale ownership, joint covariance, double-counting exclusions,
model discrepancy, and independent calibration/holdout partitions. Full W+Y
requires separate source-identical fixed-order and asymptotic inputs.
