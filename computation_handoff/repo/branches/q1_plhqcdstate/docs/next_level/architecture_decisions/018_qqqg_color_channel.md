# ADR 018: qqqg color-singlet multiplicity channel

Status: accepted for validation only.

The gluon benchmark uses the `rho` three-quark octet in which the first quark
pair is antisymmetric, coupled to the adjoint through the normalized tensor
`N epsilon_ijm (t^a)_km`. The octet multiplicity channel is recorded because
the three-quark octet is not unique.

All three fundamental generators and the adjoint generator
`(F^A)_ab = -i f^Aab` annihilate the tensor. A `qqq` singlet multiplied by a
free gluon is rejected. The diagonal zeroth-rescattering operator is labeled
`DIAGONAL_ADJOINT`, never physical `f`- or `d`-type T-odd content.
