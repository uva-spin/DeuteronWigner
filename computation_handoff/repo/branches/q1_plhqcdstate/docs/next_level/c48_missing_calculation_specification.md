# C48 missing calculation specification

It must retain symbolic L, include the 2P+ conversion and field normalization, cover every transverse numerator sector with a common unit, and produce an independently checked exhaustive tuple table before SU(3) and the 24x3 triplet isometry are inserted. No C40 array, arbitrary L, bHO rescaling, or fitted factor may supply this conversion.
