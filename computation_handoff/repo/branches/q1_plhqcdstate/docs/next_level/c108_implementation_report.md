# C108/IFCONTACT6

Status: `C108_IFCONTACT6_M2_PPLUS_AUTHORITY_INCOMPLETE`.

C107 is authenticated and supplies non-null projected coefficients and
certified bounds. C80 is authenticated for the raw W3 P-minus kernel, but
its public invariant-mass conversion remains exactly
`2*P_plus*(Pminus_coefficient)` with `P_plus` symbolic. No source-owned
finite P-plus value or enclosure is present in the C80 authority.

C108 therefore stops before products and operator entries. Choosing a
resolution-dependent P-plus, setting it to one, dropping the conversion
factor, or substituting C53/C58 would violate the frozen contracts.
