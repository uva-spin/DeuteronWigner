# C19/M0 validation API

`deuteron_wigner.matching.m0` provides immutable scheme identities, a closed
microscopic matching basis, shared LF-to-QCD mixing, step scaling, separately
accounted UV/rapidity/soft factors, rank-aware transforms, small-b OPE,
collinear and two-scale evolution, threshold matching, and resolved nuclear
transport. All objects are validation-only and production-isolated.
