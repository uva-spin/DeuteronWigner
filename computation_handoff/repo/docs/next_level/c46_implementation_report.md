# C46/HQCD fail-closed correction

C46 consumes C43/C45 and stops before allocation. C45 remains a valid one-particle library, but it does not supply the x-scaled BLFQ qg/CM projection, an action-normalized finite-volume free-operator choice, an all-mode canonical kernel, or a local residual-boundary/zero-mode functional. Producing QCD matrices from it would be a fabricated regulator realization.
