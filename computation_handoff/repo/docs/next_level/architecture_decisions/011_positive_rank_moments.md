# ADR-011: Positive-rank collinear and moment semantics

Status: accepted for C2

The scalar coefficient, contracted modulation, unweighted angular integral,
and weighted transverse moment are distinct identities. Positive-rank
physical modulations have vanishing unweighted angular integrals; a nonzero
moment requires an exact stored weight and reference mass. `J0` cannot be
used for positive rank without a named convention adapter.
