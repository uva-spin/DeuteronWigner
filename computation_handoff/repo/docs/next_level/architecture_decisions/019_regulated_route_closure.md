# ADR 019: regulated common-parent route closure

Status: accepted for validation only.

One immutable analytic parent supplies the forward TMD value, regulated
transverse-momentum GPD integral, PDF, and local moment routes. Species,
flavor, active slot, operator, path, recoil, evaluator, and stored-scalar
identities survive every route.

Every result is `REGULATED_ANALYTIC`. Equality of direct and sequential routes
tests common-parent algebra only. It is not UV matching, rapidity
renormalization, soft subtraction, link shortening, or a claim of equality
between physical staple TMDs and straight-link GPDs.
