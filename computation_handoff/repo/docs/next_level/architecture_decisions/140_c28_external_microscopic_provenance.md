# ADR 140: external ART25 and microscopic project roots remain disjoint

Status: accepted.

ART25 external proton phenomenology and the project’s microscopic light-front
spin-1 construction have different operator, scheme, scale, parameter, and
evidential roots. C28 records cross-covariance within ART25 but creates no
calibration bridge. A future bridge must explicitly own mappings, discrepancy,
joint covariance, holdouts, and double-counting exclusions.
