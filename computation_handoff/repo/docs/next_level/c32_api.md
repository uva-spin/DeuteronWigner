# C32/R0 API

`deuteron_wigner.bridge.r0.core` provides immutable, content-addressable
records for the completed operator, staple, soft/zero-bin identities,
longitudinal/transverse/endpoint regulators, zero-mode policy, external state,
common IR and gauge plans, contribution and counterterm ledgers,
distributional terms, partonic objects, matching kernels/remainders,
cancellation reports, and conditional export/bridge gates.

`exact_c11_tree_reduction_oracle()` executes the actual PLAN-A C11 and C12
code paths and tests twelve nonzero flavor/x parents. `DistributionResult`
acts exactly on test functions using delta, plus, and regular components and
provides Mellin moments without representing endpoint distributions as bins.

`MatchingGate.passes` requires operator/tree, microscopic soft, overlap, UV,
rapidity, project oracle, IR, gauge, state, trajectory, and remainder gates.
There is no fallback export, fit, inference, process, or production API.
