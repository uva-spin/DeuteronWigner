# ADR 134: CDF1.0 is an immutable native regression authority

Status: accepted.

Lock CDF1.csv by SHA-256 and require the native loader’s 50 points, the exact
historical cut’s 33 retained points, and CDF1.0 = 3.4394876804377352 pb/GeV.
The result is bin-integrated, qT-bin averaged, absolute, theory-factor applied,
and W-only. This is source-regenerated evidence, not an author-frozen output.
