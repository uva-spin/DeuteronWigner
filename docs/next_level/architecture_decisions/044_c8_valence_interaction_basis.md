# ADR 044: C8 valence interaction basis

**Decision:** Use typed free, smooth Jacobi-IR induced confinement,
effective pair color-spin, shared mass counterterm, and discrepancy blocks.

**Reason:** This is the smallest interacting basis that tests symmetry,
renormalization flow, and currents without mislabeling omitted \(qqqg\)
dynamics as canonical one-gluon exchange.

**Status:** H1 validation only.
