# C109/IFM2NORM

Status: `C109_IFM2NORM_PMINUS_NORMALIZATION_INCOMPLETE`.

The frozen convention is `-L <= x^- <= L`, `p_i^+=pi*k_i/L`,
`P^+=pi*K/L`, with K=`9/2,11/2,13/2` and symbolic L. Two independent
longitudinal routes agree on `(2L)^-2 * (2L) * L/(pi*K_channel)`, so the
explicit longitudinal L cancels.

C80 nevertheless combines that dimensionless longitudinal factor with a
four-HO overlap carrying `b_HO^2` (GeV²), while declaring the stored
P-minus coefficient in GeV. Its M² field remains `2*P_plus*Pminus` with
P-plus symbolic. Thus the true P-minus normalization is incomplete; C109
does not choose P-plus/L and forms no products or contact entries.
